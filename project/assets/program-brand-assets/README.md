Trail Crew is the team within Trail of Mastery. It uses the same Charcoal, Cool Gray, and Trail Light palette with its own tree patch. Pair the mark with the program or team name in headings, announcements, and any place where the identity needs to be clear at a glance.

## Files in each set

- **Badge SVG** scales for Canva, the web, and print.
- **Badge PNG** is a transparent 1024 × 1024 export for Canva and tools that require raster images.
- **Symbol SVG** is a single-color mark for light backgrounds and supporting graphics.
- **Emoji PNG** is a transparent 128 × 128 square for Slack. Upload it with the alias in the table.

Use Trail Light `#FAFAF7` or the approved companion surface when a layout needs a light background. Place the icon next to a text label and use the badge shape and symbol alongside color. Use the program marks as identifiers within Transition Trails materials.

The Foundations, Guided, and Mastery lead colors come from [program.css](../../tokens/program.css). Digital Compass uses the Sky Blue and Deep Teal family from [partner.css](../../tokens/partner.css) and [site.css](../../tokens/site.css). The Explorer's Trail treatment pairs the Expedition dark and Sky Blue from [site.css](../../tokens/site.css). The remaining core colors and tints are defined in [colors.css](../../tokens/colors.css).
