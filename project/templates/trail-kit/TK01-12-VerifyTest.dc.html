If a test failed

Write down what you saw, then turn to When it goes wrong. Fix one thing at a time and run the test again.

Watch out
For test 4, go to Setup › Users, open your test user and click Login. Use Log out as in the banner to come back.
Pro tip
Take a screenshot each time a test passes. You'll need them for Prove it.
Remember
Use the same time window you set in Prepare. Don't stretch it after the fact.
