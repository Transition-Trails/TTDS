## Page anatomy

Every page is 816 x 1056 (Letter), paper `#FBF7F0`, with a header line (kit name and tab), a main column, a 200px rail on the right and the vertical tab strip (Orient, Prepare, Build, Verify, Next Trail). The rail holds the notes: **Watch out** (Clay), **Pro tip** (Trail Green), **Remember** (Deep Teal), **What it does not do**, and ruled **Your notes** lines. Each page carries one Penny box, labeled "Penny, your trail guide": one sentence, then one bolded question. Build steps are numbered, one action each, with menu paths in bold and a "You should see:" line. Screenshots sit under "What it looked like in our practice org."
