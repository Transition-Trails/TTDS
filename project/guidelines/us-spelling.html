Applies to every artifact — kits, slides, screens, email, component copy, code comments, file names. Our audience is US nonprofits and US learners; mixed conventions in one sentence read as careless on something people pay for. "License" is both noun and verb — this one has regressed twice, so check it explicitly wherever permitted use is discussed. Sweep new work against this list before shipping.
