Copy all four into a Replit app root, dropping the .txt from the two scripts. Targets Tailwind v4 — both TT apps run it, and v4 removed presets, so there is no config step.

tt-tokens.css
Every token as a custom property, plus a @theme inline block that registers the Tailwind v4 utilities. Generated from the live sources, so it cannot drift.
replit.md
What the agent reads before it writes code, so a new app starts correct rather than being corrected.
tt-check.mjs.txt
Build guard — fails on raw hex, British spelling, emoji, and prohibited ecosystem terms.
tt-sync.mjs.txt
npm run tt:sync pulls the latest tokens from GitHub and prints which ones were added or removed.
The design system, Trail OS, and the public site currently run three token conventions with three divergent values — see guidelines/token-divergence.md.
